# Minecraft 地图汉化器

Android 原生应用，用于离线提取 Minecraft 基岩版地图文字，导出 JSON 翻译表，导入外部填写的译文，并验证后导出新地图。应用不包含机器翻译模型，也不请求网络权限。

## 使用

1. 选择 `.mcworld`、ZIP 或地图文件夹，等待地图验证完成。
2. 选择一种或多种原文语言，点击「提取文字」。提取可以暂停并继续。
3. 点击「导出翻译表」获得**一个 JSON 文件**；也可以单独选择「分批导出翻译表」获得 ZIP。
4. 在外部翻译工具中填写 `translation`，保留 ID、原文、路径、占位符、格式代码及其他字段。
5. 点击「导入翻译表」选择单个 JSON 或 ZIP，或点击「批量导入翻译表」一次选择多个文件。检查预览后按冲突处理方式提交。
6. 审阅译文，点击「验证并导出地图」。未翻译、校验失败和保留原文的条目仍保留原文。

分批 ZIP 包含 `manifest.json` 和多个 JSON；每批默认 500 条，按实际 UTF-8 字节限制单批大小。导入按记录 ID、原文及来源结构匹配，不按行号。旧版单文件 JSON 仍可导入。普通单文件导出逐条写入，不受原先 8 MiB 限制。

应用仅处理工作副本，原地图不会被覆盖。Bedrock 部分格式尚未覆盖，NPC 数据库对话仍未支持；游戏内重新导入需要在实际地图上验收。

## 构建

在 GitHub Actions 的 **Build APK** 运行页面下载 `MinecraftWorldTranslator-debug`。源码不再包含 ONNX 模型，构建无需 Git LFS 下载模型。项目使用 Android SDK 36、NDK 27.2.12479018、CMake 3.22.1 和 Java 17。
